# TerraForge FINAL — Solo Operator Guide

**One human. Bots run the rest. Revenue to your company wallet.**

## One-click deploy

### Local
```bash
python3 -m http.server 8765
```

### Cloud
Upload this repo folder to Netlify, Cloudflare Pages, Vercel, or S3/R2. No build step.

## Revenue
1. Open Settings (⚙)
2. Paste Treasury wallet (company-controlled)
3. Save

All claim, mint, market, seal, and module fees credit that ledger.

## No admin team
Economy self-corrects. World self-expands. No chat/UGC feed requiring moderation in this build.
